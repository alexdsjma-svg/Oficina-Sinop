Importar agenda

Importe XLSX, XLS ou CSV. Inclua a coluna de códigos de operação para criar os serviços automaticamente.

Colunas reconhecidas: Placa, Cliente, Veículo, Horário, Relato, Consultor, Telefone, OS, Data e Códigos de Serviço/Operação. Separe vários códigos por ponto e vírgula ou barra vertical. Em CSV com separador ';', prefira a barra vertical (|). Códigos ainda não cadastrados entram no catálogo com tempo padrão 0 para posterior configuração.

Instalar como aplicativo

Publique a pasta em um endereço HTTPS para instalar em tablets e celulares.

Android/tablet: abra o endereço no Chrome ou Edge → menu → Instalar app / Adicionar à tela inicial.
iPhone/iPad: abra no Safari → Compartilhar → Adicionar à Tela de Início.
Importante: esta versão usa autenticação e sincronização central pelo Supabase. O navegador mantém uma cópia local de contingência.
