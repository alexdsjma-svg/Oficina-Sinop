# Migração online do Oficina Sinop

Esta pasta contém a preparação para a versão multiusuário.

- `supabase-schema.sql`: banco, autenticação e políticas RLS.
- `supabase-config.js`: configuração pública do cliente, preenchida após criação do projeto.
- O `service_role` nunca deve ser colocado no HTML ou no GitHub Pages.

A versão pública atual continua funcionando enquanto a migração não for concluída.
